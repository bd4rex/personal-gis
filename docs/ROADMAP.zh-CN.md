# 路线图

> [English](ROADMAP.md) | 简体中文 · 快照 `2026-08-03T23:12:23+08:00`

## 已完成基础

- 江苏、安徽独立 PMTiles，具备清单、回退、启停、校验、重建、更新和受保护删除。
- 本地 OSM Carto 作为默认熟悉地图，PMTiles 作为交互矢量备选。
- 中国 34 个省级目录与 550 多个 Geofabrik 区域目录。
- Natural Earth 全球概览及明确的离线/OSM Standard/OpenFreeMap 来源控制。
- 个人点位、集合、轨迹、备注、标签、评分、媒体所有权、乐观版本、审计、GPX、GeoJSON 与 ZIP 导出。
- 轻量 OSM 参考搜索与 Nominatim 地址/反查。
- Valhalla 驾车、骑行、步行路线、海拔和轨迹保存。
- HGT、Terrarium、地形阴影、等高线、天气、航海、应急、维基百科与维基导游。
- 缓存优先资源盘点、真实维护队列、实测进度、更新、回退与磁盘分类。
- 每日校验个人备份，以及包含 Nominatim/OSM Carto 快照的 schema-v4 恢复包。
- 健康、API 生命周期、资源页面、主地图、全球地图与隔离恢复测试。

## 近期优先项

1. 把性能敏感运行资源和可再生构建临时数据迁入 Linux 原生 Docker 卷，同时保留经过校验的宿主机恢复副本。
2. 在测试流程加入双语文档对等和链接自动检查。
3. 历史里程碑文档验收后建立明确的 tag/Release 流程。
4. 改善有限内存下的本地搜索延迟、查询取消和界面防抖。
5. 支持共享搜索/路线范围扩展，避免静默保留已删除区域。
6. 完成隔离 OSM 增量更新试验，继续以完整快照作为灾备基线。

## 中期工作

- 评估 QField、Mergin 或轻量 API 后加入可选手机采集/同步。
- 增加访问历史、附件、导入对账和用户可见变更历史。
- 增加更多独立国家/地区包并校准构建估算。
- 单个共享索引过重时拆分区域搜索/路线产品。
- 为受认证局域网部署建立独立配置，不改变当前 localhost 模式。

## 长期方向

不强制使用一个全球 z16 地图、地理编码库或路线图。通过本地全球概览、独立高细节区域包、可选区域能力索引和一个持久个人 PostGIS 扩展。

渲染器、目录与派生引擎演进时，个人数据模型必须保持稳定。
